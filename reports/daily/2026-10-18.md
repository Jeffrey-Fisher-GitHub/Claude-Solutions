## 4. Academic articles

**LLMs extend known research but do not create new research directions** - [arXiv:2610.17439](https://arxiv.org/abs/2610.17439)
The authors embedded 26.9 million papers and over 500,000 LLM-generated hypotheses to measure novelty by distance and by direction (an "orthogonal novelty score"). LLM ideas were farther from existing work but 15-23% lower in directional novelty, so they stay within established lines of inquiry.

**Claude and quantum circuit optimization** - [Anthropic Research](https://www.anthropic.com/research/designing-efficient-quantum-circuits) (as summarized by AI Weekly; page not directly fetched)
Anthropic reports the model beat published constructions on eight tasks, including large gate-count reductions in one decoder at the cost of some extra qubits in a variant. This is a company report rather than peer-reviewed work.

**Machine translation quality annotation with LLMs** - [arXiv:2610.10918](https://arxiv.org/html/2610.10918v1)
Listed in search results with the title stating that humans and models are both challenged on annotating translation quality. I did not read the full paper.

## 5. Java and better code

Note: JDK 27 shipped Sep 15, 2026, so it is outside the 48-hour window, but it is the freshest major Java news. I found no clearly dated Oct 16-18 Java framework releases.

**JDK 27 is generally available (non-LTS)** - [Oracle Java blog](https://blogs.oracle.com/java/the-arrival-of-java-27), [InfoWorld](https://www.infoworld.com/article/4202901/jdk-27-the-new-features-of-java-27.html)
Nine JEPs including G1 as the default GC everywhere (JEP 523), compact object headers by default (JEP 534), and hybrid post-quantum key exchange for TLS 1.3 (JEP 527). Oracle's performance claims are qualitative, so students should benchmark for themselves.

**Language previews continue maturing** - [InfoWorld](https://www.infoworld.com/article/4202901/jdk-27-the-new-features-of-java-27.html)
Primitive types in patterns, instanceof and switch (JEP 532, fifth preview), structured concurrency (JEP 533, seventh preview), and lazy constants (JEP 531, third preview) continue to refine. They are good material for discussing how language design evolves slowly.

**Tooling and security hygiene** - [Oracle Java blog](https://blogs.oracle.com/java/the-arrival-of-java-27)
JFR can now redact command-line arguments, environment variables, and system properties before recordings leave the process (JEP 536), and a new API handles PEM-encoded keys and certificates (JEP 538).

**Testing ecosystem** - [JUnit 5 vs JUnit 6 guide](https://howtodoinjava.com/junit/junit-5-vs-junit-6/), [Baeldung on Spring Boot 4](https://www.baeldung.com/spring-boot-4-spring-framework-7)

## Teaching ideas for CISC 121

1. **Lab: "Is the AI bubble in the data?"** Give students a small CSV of daily prices for AI-related tickers plus a broad index around Oct 12-16. They compute returns and correlations in Python, then discuss why concentration risk and earnings-growth assumptions (the Jefferies projection) matter for evaluating AI hype.
2. **Lecture and activity: Novelty vs. recombination.** Using arXiv:2610.17439, explain embeddings and distance measures. Students embed a handful of paper abstracts and LLM-generated hypotheses with a free embedding model, compute distances, and debate whether "far" means "new."
3. **Java lab: Benchmark before you believe.** Oracle's JDK 27 claims about G1 and compact object headers are qualitative. Students write a small allocation-heavy Java program, run it on JDK 26 or 27 with different GC and header flags, and report heap size and latency, tying into responsible evaluation of ML systems too.
