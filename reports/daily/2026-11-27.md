## 4. Academic articles on AI
- **Language Models Make New Research Sound Old** - [arXiv:2611.23546](https://arxiv.org/abs/2611.23546) (Nov 17). LLMs tend to describe open research questions as partly solved. A fixed-answer procedure raised correct "still open" reporting from 8% to 95% for one model.
- **Learning to Reason in Real-Time** - [arXiv:2611.33513](https://arxiv.org/abs/2611.33513). Trains agents to trade thinking time against a changing environment, beating baselines by 33% reward in distribution and 55% out of distribution on Frogger and Snake.
- **Structured Harm Assessment for Mental Health Safety** - [arXiv:2611.33263](https://arxiv.org/abs/2611.33263). A clinically grounded harm taxonomy and a 35B guard model reportedly matching a much larger model at about one-tenth the latency.
- **AutoformBench** - [arXiv:2611.33165](https://arxiv.org/abs/2611.33165). 341 Lean 4 tasks where agents must build missing definitions and lemmas; success depends more on that infrastructure than on the math domain.
- **Constraint-Aware Test-Time Scoring** - [arXiv:2611.33161](https://arxiv.org/abs/2611.33161). Applying hard checks before soft scoring of candidate answers accounts for most of the gains.

## 5. Java and better code
*Source: Baeldung and InfoQ summaries; verify JEP numbers on openjdk.org.*
- **JEP 534, compact object headers by default** - [Baeldung](https://www.baeldung.com/java-27-new-features). Smaller object headers are now on by default (opt out with a JVM flag), reducing heap use.
- **JEP 523, G1 default GC everywhere** - [Baeldung](https://www.baeldung.com/java-27-new-features). The small-machine exception that picked Serial GC is gone, so small containers also get G1.
- **JEP 527, post-quantum hybrid key exchange for TLS 1.3** - [Baeldung](https://www.baeldung.com/java-27-new-features). Combines classical ECDHE with ML-KEM so security holds if either fails.
- **JEP 536, JFR in-process data redaction** - [Baeldung](https://www.baeldung.com/java-27-new-features). Masks passwords and tokens inside the JVM before they reach profiling recordings.
- **Previews to watch** - [Baeldung](https://www.baeldung.com/java-27-new-features). Structured Concurrency (with breaking API changes), primitive types in patterns/switch, lazy constants and the Vector API incubator. No feature graduated from preview; Java 29 is the next LTS.

## Teaching ideas for CISC 121
1. **Lab: "Why did the AI trade whipsaw?"** Students download a small price dataset for Nvidia and a chip ETF, then compute daily returns, volatility and a rolling correlation in Python. They test whether a simple model can predict next-day direction and discuss why it fails around a sudden news shock (data drift, non-stationarity).
2. **Lecture and debate: model release cadence and evaluation.** Use this month's Gemini 4, GPT-6.2 and Claude releases, plus the "Language Models Make New Research Sound Old" paper, to compare benchmarks, prices and hallucination claims. Students write a one-page procurement memo choosing a model for a stated use case and justify it with evidence and caveats.
3. **Lab: AI-agent security and governance tabletop.** Based on the Swiss AI-agent attacks and the California suit, student teams design guardrails for a toy tool-using agent (allow-lists, logging, human approval, JFR-style redaction of secrets) and map them to NIST AI RMF functions. Optionally, extend with a Java 27 task that adds redaction and structured concurrency to the agent's tool calls.
