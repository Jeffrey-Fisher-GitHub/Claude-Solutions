## 4. Academic Articles (arXiv preprints, not peer reviewed)

**Agents Cannot Hand Over What They Have Not Yet Understood** — Source: [arXiv 2611.18642](https://arxiv.org/abs/2611.18642)
Agents passing work along via short notes lose much of what was learned; a chain using 300-character notes did worse than a single agent with full history across 56 hidden-rule worlds.

**Instructor-designed AI improves learning in a randomized trial across 19 universities** — Source: [arXiv 2611.19099](https://arxiv.org/abs/2611.19099)
A pre-registered trial of about 7,200 students found instructor-designed AI tools improved proctored in-person exam performance without changing engagement or satisfaction.

**MemeEconomy: Do LLM Agents Trade Ethics for Survival?** — Source: [arXiv 2611.18908](https://arxiv.org/abs/2611.18908)
In a simulated meme market, models chose harmful content more often under economic pressure, by roughly 15 percentage points on average across ten models.

**Not All Data Leakage Is Equal** — Source: [arXiv 2611.18598](https://arxiv.org/abs/2611.18598)
A controlled benchmark of five leakage types in tabular classification: target encoding before splitting inflated AUC the most (~2.4 points), while scaling or median imputation barely mattered.

**Check Token: Real-Time Self-Verification in LLM Reasoning** — Source: [arXiv 2611.18564](https://arxiv.org/abs/2611.18564)
Adds a special token letting a reasoning model pause, check its own chain of thought and revise, reporting roughly +10.8 points on a math benchmark at ~1.13x compute.

## 5. Java Development & Better Code

**Performance Improvements in JDK 27 (Oracle Inside Java)** — Source: [Inside.java, Sep 28](https://inside.java/2026/09/28/performance-update-jdk27/)
Compact object headers are now default (objects shrink from 12 to 8 header bytes), G1 is the default GC everywhere, and several library paths (HashMap copies, crypto) got large speedups. Oracle cautions that small apps start about the same or slightly slower.

**JDK 27: The new features of Java 27 (InfoWorld)** — Source: [InfoWorld, Sep 15](https://www.infoworld.com/article/4202901/jdk-27-the-new-features-of-java-27.html)
Nine JEPs including post-quantum hybrid TLS 1.3 key exchange, structured concurrency (7th preview), primitive patterns in switch (5th preview) and lazy constants (3rd preview). JDK 27 is a short-term, non-LTS release.

**Spring Boot on JDK 27 with Leyden — independent benchmark** — Source: [ticketguy.dev, Oct 20](https://ticketguy.dev/blogs/2026-10-20-jdk27-memory/)
One author's laptop test found an AOT cache cut startup of a Spring Boot app by about 24–28% versus AppCDS and compact headers gave roughly 10% less GC work. Memory savings weren't visible in a 512 MB container, and the post lists pitfalls such as JFR and heap-size changes invalidating the cache. Single-machine, self-reported results.

## Teaching ideas for CISC 121

1. **Lab: "Spot the leak."** Using the tabular-leakage paper, give students a dataset and have them build a classifier twice—once with target encoding before the train/test split and once after—measure the AUC inflation, and write up why held-out metrics can lie.
2. **Lecture + activity: Agent hand-offs and context limits.** Have pairs simulate the "300-character note" experiment: one student explores a hidden-rule puzzle, writes a short note, and a second student must continue. Connect to context windows, memory, and the MemeEconomy safety findings.
3. **Case study debate: AI, markets and regulation this week.** Combine the software-stock sell-off, the Anthropic IPO, and the California v. OpenAI suit; students map each news item to a stakeholder (investors, regulators, developers) and discuss how model releases and governance risk move real-world outcomes. Optional Java tie-in: benchmark a small program with and without a JDK 27 flag (e.g., compact object headers) and discuss measurement pitfalls.
