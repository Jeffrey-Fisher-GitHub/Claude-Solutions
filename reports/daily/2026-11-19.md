## 4. Academic articles on AI (arXiv, Nov 18 digest)

**Ambient LLMs: Data-Efficient SFT via Temperature Matching** - [arXiv 2611.23229](http://arxiv.org/abs/2611.23229v1)
Proposes matching sampling temperature to curb overfitting when fine-tuning on small datasets.

**Agent Trust Infrastructure (ATI)** - [arXiv 2611.23202](http://arxiv.org/abs/2611.23202v1)
A federated architecture for identity, attestation and accountability among AI agents across organizations.

**Reading Scene States: Safety Failures in Vision-Language Models** - [arXiv 2611.23206](http://arxiv.org/abs/2611.23206v1)
Shows VLMs can give harmful help by interpreting scenes without an explicit harmful request; introduces SceneSafetyBench (375 image-question pairs).

**Do LLM Agents Still Need to Be Told How to Self-Improve?** - [arXiv 2611.23219](http://arxiv.org/abs/2611.23219v1)
Finds the need for human-written self-improvement guidance shrinks as models grow more capable.

**Spool: Low-Latency Streaming Inference for Hybrid VLMs** - [arXiv 2611.23228](http://arxiv.org/abs/2611.23228v1)
A streaming framework mixing attention and linear recurrent layers for fast answers about recent video.

## 5. Java development and better code

**Compact Object Headers default (JEP 534)** - [Inside.java](https://inside.java/2026/09/28/performance-update-jdk27/)
Headers shrink from 12 to 8 bytes; gains vary by object mix and it can be disabled with a flag.

**Measured on Spring Boot** - [ankurm.com](https://ankurm.com/what-actually-got-faster-in-jdk-27-measured-spring-boot/)
On a small box, throughput, p99 and startup were indistinguishable from JDK 25; live heap dropped about 24 MiB, matching JDK 25 with the header flag on.

**G1 default everywhere (JEP 523)** - [Inside.java](https://inside.java/2026/09/28/performance-update-jdk27/)
Small containers no longer fall back to Serial GC by default; watch pause times and memory in constrained environments.

**Faster HashMap bulk copy** - [Inside.java](https://inside.java/2026/09/28/performance-update-jdk27/)
putAll and the copy constructor gain a fast path, reported 61-86% faster on Graviton for a 150-entry map.

**Lazy Constants, third preview (JEP 531)** - [Inside.java](https://inside.java/2026/09/28/performance-update-jdk27/)
LazyConstant<T> computes once on first use so the JVM can treat it like a final; still needs --enable-preview.

## Teaching ideas for CISC 121

1. **Lab: Agent safety red-team.** Using the SceneSafetyBench and agent-trust papers, students design test prompts for a vision-language or agent system and document failures, then propose a mitigation.
2. **Lecture: Why data-efficient fine-tuning matters.** Use the temperature-matching paper to demo overfitting on a tiny dataset in a notebook, then compare techniques to reduce it.
3. **Lab: Java memory profiling.** Have students allocate many small objects, then compare heap use under compact object headers on/off and G1 vs Serial, linking to ML workloads where memory efficiency matters.
