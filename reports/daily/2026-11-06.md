# Daily AI & Java Research Digest - 2026-11-06

Prepared for CISC 121 Introduction to AI and Machine Learning. Sources are mostly secondary aggregators; items marked (unverified) were not confirmed against a primary source. Stock content is informational, not financial advice.

## Top takeaways

- Nov 5 was a brutal day for AI-linked equities: the S&P 500 fell about 4.4%, the Nasdaq Composite about 5.5% (into correction territory), and semiconductors about 12%, as the midterm outcome raised fears of tighter AI and data-center regulation.
- Data-center electricity costs and local opposition have become a political issue; OpenAI responded by pledging to pay full power and infrastructure costs for data centers it operates.
- US AI policy is moving at the state and congressional level: new chatbot-and-minors laws, state attorney-general suits against OpenAI, a DHS ban on DeepSeek in federal civilian agencies, and several new federal bills.
- Frontier labs shipped a dense October (Gemini 4, GPT-6 variants, Claude Duet preview, Meta open weights), but trackers disagree on details, so verify before using specific names or benchmarks in class.
- JDK 27 (Sept 2026) made G1 the default GC everywhere, turned on compact object headers, and added post-quantum hybrid TLS; JDK 28 is expected to bring Valhalla value objects and a JSON API.

## 5. Java development

- **JDK 27 GA (Sept 15)** - [Inside.java](https://inside.java/2026/09/15/jdk-27-available/) and [InfoWorld](https://www.infoworld.com/article/4202901/jdk-27-the-new-features-of-java-27.html). Nine JEPs including post-quantum hybrid key exchange for TLS 1.3, G1 as the default collector everywhere, and compact object headers on by default. It is a non-LTS release with about six months of support.
- **Preview features still maturing** - Same sources. Primitive types in patterns (fifth preview), structured concurrency (seventh preview), lazy constants (third preview) and the Vector API (12th incubator) continue to iterate.
- **Why it matters** - [InfoWorld, Simon Ritter](https://www.infoworld.com/article/4229750/jdk-27-the-quiet-before-the-storm.html). Compact headers are cited as cutting heap use about 22% and CPU about 8% on a standard benchmark. The author also notes a delayed release candidate after a critical security patch, linked to AI tools finding vulnerabilities faster.
- **JDK 28 preview** - Same article. Targeted items include a strict JSON API and Valhalla value objects.
- **API changes to know** - [HappyCoders](https://www.happycoders.eu/java/java-27-features/). Structured concurrency's API shifted again (type parameter on the scope, renamed timeout method).
- No Spring Boot, testing or clean-code news turned up in the pages read.

## Teaching ideas for CISC 121

1. **Lab: market-reaction sentiment analysis.** Give students a small set of headlines from Nov 3-5 plus price changes and have them build a simple text classifier (or prompt an LLM) to label regulatory-risk vs. earnings news, then discuss why correlation is not prediction and why overfitting on a handful of days is a trap.
2. **Lecture: "Who funds the compute?" and AI's physical footprint.** Use the data-center power-cost pledge and ballot measures to connect model scale, energy, ESG and policy, tying into the course's existing ESG data-center readings.
3. **Lab: evaluating vendor claims.** Compare two trackers' conflicting reports on Google's Gemini 4 release and the self-reported cyber-bug numbers; students write a short source-verification protocol (primary source, self-reported vs. independent benchmark) and apply it to one claim. Optionally extend with a Java exercise exploring JDK 27's compact object headers and a simple memory benchmark.
