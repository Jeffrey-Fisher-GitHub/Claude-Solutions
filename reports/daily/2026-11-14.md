## 2. AI regulation and policy

**EU AI Act: marking obligations land Dec 2, 2026**
Source: [CASRAI explainer](https://casrai.org/news/eu-ai-act-2-december-2026-obligations-article-50)
Under the July 2026 Digital Omnibus on AI, providers of generative systems already on the market must make AI output machine-readable-marked by Dec 2. ## 4. Academic articles on AI

**Do Machine Learning Models Predict?**
Source: [arXiv 2611.12332](https://arxiv.org/abs/2611.12332)
The authors examine the philosophical line between fitting known evidence and genuine prediction, arguing the distinction blurs for ML models. Most successful ML results therefore behave more like accommodation, with implications for how we judge confirmation and novelty.

**When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents**
Source: [arXiv 2611.14326](http://arxiv.org/abs/2611.14326v1)
The paper retains agent "lessons" only if they pass a verification test on new tasks, preventing stale strategies from persisting. Summary is based on a digest, not the paper itself.

**AI Isn't Getting Dumber, We're Getting Pickier**
Source: [arXiv 2611.14333](http://arxiv.org/abs/2611.14333v1)
Using Chatbot Arena data, the authors argue perceived quality declines reflect stricter human raters, not model degradation. Summary is based on a digest.

**REAL Loss for Speculative Decoding**
Source: [arXiv 2611.14399](http://arxiv.org/abs/2611.14399v1)
A training objective for the draft model that directly optimizes expected acceptance length, aiming at faster inference without quality loss. Summary is based on a digest.

**Medical Image Segmentation: Foundation Model Adaptation versus Task-Specific Training**
Source: [arXiv 2611.14519](http://arxiv.org/abs/2611.14519v1)
Benchmarks adapting foundation models like SAM against task-specific training; task-specific models stay competitive, especially with scarce or shifted data. Summary is based on a digest.

## 5. Java development and better code

**Java 28 feature set takes shape**
Source: [HappyCoders](https://www.happycoders.eu/java/java-28-features/)
Java 28 is scheduled for March 9, 2027 with Rampdown Phase One on Dec 3, 2026. Value Objects arrive as a preview (JEP 401), giving identity-free classes whose == compares fields, and Lazy Constants is proposed for a fourth preview.

**Structured Concurrency becomes final (JEP 543)**
Source: [HappyCoders](https://www.happycoders.eu/java/java-28-features/)
Subtasks are forked in a scope and joined at one point, with failures cancelling siblings. From Java 28 it no longer requires preview flags, which makes it teachable in an intro course.

**Simple JSON API incubator (JEP 540)**
Source: [HappyCoders](https://www.happycoders.eu/java/java-28-features/)
A small JSON reader/writer in an incubator module targets simple use cases without Jackson or Gson. It is not intended to replace data-binding or streaming libraries.

**Performance improvements in JDK 27**
Source: [Inside Java](https://inside.java/2026/09/28/performance-update-jdk27/)
JDK 27 has 2,300+ commits since JDK 26, with Compact Object Headers and G1 as default collector now on by default. The authors caution that microbenchmark gains depend heavily on hardware and workload.

No fresh testing or clean-code items were found in the sources reviewed this run.

## Teaching ideas for CISC 121

1. **Lab: "Are the models getting worse, or are we getting pickier?"** Give students a small set of pairwise preference ratings and have them compute win rates under different rater-strictness thresholds, echoing the Chatbot Arena paper. Discussion: evaluation bias and why benchmark trends can mislead.
2. **Lecture and debate: Agents that spend money.** Use ChatGPT Wallet and United's booking ban as a case study on autonomy, authorization, liability and platform control. Students map an agent's action space, then draft guardrail policies tied to NIST AI RMF and the EU AI Act marking duty.
3. **Java lab: Structured concurrency for parallel model calls.** Students write a scoped fan-out that queries several mock "model endpoints," cancels siblings on failure, and compares with plain threads. This reinforces Java 28's soon-final feature and error handling in AI pipelines.
